# Day 2: Loops and Data Structures

## Topics Covered
- Control flow using `for` and `while` loops, `break`, `continue`, and `range()`.
- Data filtering and cleaning strategies.
- Advanced list processing and list comprehensions.
- Set operations (Union, Intersection, Difference).
- Working with Dictionaries and Dictionary Comprehensions.
- Handling nested dictionaries for structured data storage.

## Exercises Completed
1. Batch Processor: Iterated through batch numbers and implemented checkpoint alerts using the modulo operator.
2. Retry Simulation: Built a `while` loop logic structure with attempt counters, early loop breakage, and success simulation.
3. Clean Numeric Values: Filtered invalid data types from mixed lists using both explicit loops (`continue`, `isinstance`) and list comprehensions.
4. Sales List Analysis: Sorted financial data, calculated taxes using mapping, and gathered statistical totals/averages.
5. Dataset Comparison: Used mathematical set operations to isolate shared and distinct elements across collections.
6. Student Score Dictionary: Managed key-value student performance data, filtered scores using dictionary comprehensions, and evaluated top performers.
7. Nested Order Summary: Iterated through multi-level dictionaries to aggregate status conditions and add new records safely.
8. Stretch Contact Book: Developed an interactive command-line application featuring nested dictionary structures and crash-safe error handling.

## What I Learned
- How to efficiently streamline data transformation using list and dictionary comprehensions instead of verbose loops.
- The power of set theory methods (`union`, `intersection`, `difference`) for tracking relational changes across data groups.
- Writing robust user-input validation checks in terminal menus to prevent `KeyError` crashes.

## Challenges Faced
- Managing proper formatting and indentation inside multi-layered nested dictionary lookups for orders and contacts.
- Ensuring the interactive `while` loop cleanly catches non-existent key requests without halting program execution.
